## 2. Current Implementation Summary

### Model Architecture (`model_training.py`)
- **Base Network:** Pretrained VGG19 (`weights="imagenet"`, `include_top=False`, `input_shape=(224, 224, 3)`).
- **Freezing:** All convolutional layers in `base_model` are set to `layer.trainable = False`.
- **Classification Head:**
  - `Flatten()`
  - `Dense(128, activation='relu')`
  - `Dropout(0.5)`
  - `Dense(4, activation='softmax')`
- **Loss & Optimizer:** `categorical_crossentropy`, `Adam` optimizer, metric `['accuracy']`.
- **Training Epochs:** 6 epochs, batch size 32.

### Image Preprocessing & Classes
- **Input Dimensions:** `224 x 224 x 3` (RGB).
- **Training Preprocessing:** `ImageDataGenerator(rescale=1./255, validation_split=0.2)`. Pixel normalization scaled to `[0, 1]`.
- **Inference Preprocessing (`app.py`):**
  - Resized to `(224, 224)` via `tf.keras.preprocessing.image.load_img`.
  - Converted to array with `img_to_array`.
  - Expanded dims to `(1, 224, 224, 3)` and divided by `255.0`.
- **Target Classes (4 Categories):**
  1. Index 0: `Cataract`
  2. Index 1: `Diabetic Retinopathy`
  3. Index 2: `Glaucoma`
  4. Index 3: `Normal`
  *(Matches alphabetical order generated by Keras `flow_from_directory`).*

### Inference Web Service (`app.py`)
- Monolithic Flask service loaded on port 5000.
- Reads `models/eye_disease_model.h5` globally on startup (`load_model`).
- Single route `/` handling GET and POST.
- Saves uploaded image to `static/uploads/` and passes prediction label and path to Jinja2 template.

## 4. Issues Identified

1. **Missing Model Weights & Dataset Artifacts:**
   - Attempting to run `app.py` fails immediately with `OSError: Unable to open file (unable to open file: name = 'models/eye_disease_model.h5')`.
   - Attempting to run `model_training.py` fails with `FileNotFoundError: [Errno 2] No such file or directory: 'dataset'`.
2. **Keras Evaluation Shuffle Bug (`model_training.py` lines 56–58):**
   - In `model_training.py`, `val_data = datagen.flow_from_directory(..., subset="validation")` does not set `shuffle=False`.
   - Consequently, calling `val_preds = model.predict(val_data)` generates predictions in randomly shuffled order, while `y_true = val_data.classes` reads classes in generator sequence.
   - This label-prediction misalignment explains the **25% accuracy** shown in `project_structure.jpg` (pure random chance across 4 balanced classes).
3. **Absence of Data Augmentation:**
   - `model_training.py` only applies `rescale=1./255`. No geometric or photometric data augmentations (rotations, horizontal flips, contrast adjustments) were defined, causing high susceptibility to overfitting on fundus images.
4. **VGG19 Preprocessing Deviation:**
   - Standard VGG19 models trained on ImageNet use caffe-style preprocessing (subtracting ImageNet channel means `[103.939, 116.779, 123.68]` and BGR color order).
   - The script uses `1./255` scaling (RGB `[0, 1]`). All inference logic must continue to use `1./255` or be uniformly migrated.
5. **Legacy Model Format Warning:**
   - Keras 3.x flags `.h5` as legacy in favor of `.keras` format (as recorded in the author's terminal log in `project_structure.jpg`).
6. **Missing Templates & Static Files:**
   - `templates/index.html` and `templates/result.html` are completely missing.
7. **Git Configuration Naming:**
   - The repository included `gitignoresourcefile.gitignore` rather than `.gitignore`, leaving local builds and temp files untracked.
